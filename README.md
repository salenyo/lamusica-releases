# lamusica

**Музыкальный сервис, который собирает треки со всех площадок в одном плеере.**

YouTube, SoundCloud, Spotify, Яндекс.Музыка — один поиск, одна библиотека, один плеер
вместо десятка вкладок.

## Возможности

**Всё в одном месте.** Поиск сразу по YouTube, SoundCloud, Spotify и Яндекс.Музыке.
Площадки опрашиваются параллельно, и результаты появляются по мере ответа — не нужно ждать
самую медленную.

**Твоя библиотека.** Лайки, плейлисты, жанры — треки сохраняются и открываются мгновенно.

**Чарты и рекомендации.** Мировые и региональные чарты плюс подборка, которая учится на
твоих лайках и подкидывает похожее.

**Звук под себя.** 10-полосный эквалайзер с пресетами и живой визуализатор спектра.

**Внешний вид под себя.** Светлая и тёмная темы, свои цветовые схемы, любой фон и
регулируемая ширина панели.

**Управление как у нативного плеера.** Медиа-клавиши и системные виджеты — обложка,
перемотка, кнопки на гарнитуре.

**Играет сразу.** Трек стартует после первых секунд загрузки, остальное докачивается
фоном; прослушанное остаётся в кэше и второй раз не качается.

**Обновляется само.** Новые версии проверяются по цифровой подписи и ставятся в один клик.

## Установка

| ОС | Файл | Примечание |
|----|------|------------|
| **Windows** | `lamusica-app_<версия>_x64-setup.exe` | обычный установщик |
| **macOS** | `lamusica-app_<версия>_universal.dmg` | при первом запуске: правый клик → **Open** |
| **Linux** | `.AppImage`, `.deb` или `.rpm` | AppImage нужно сделать исполняемым: `chmod +x` |

## Обновления

Приложение проверяет обновления при запуске, а в настройках есть кнопка ручной проверки.
Новая версия скачивается и ставится в один клик — вручную качать заново не нужно.
